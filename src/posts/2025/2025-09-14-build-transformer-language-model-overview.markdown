在之前的文章中，我们[实现了 Tokenizer](/2025/2025-09-07-tokenizer-with-bpe)，主要是将输入的自然语言文本转成 Token ID 序列，本文就来讲一下大语言模型在接收到 Token ID 后干了啥。

首先来了解一下大语言模型内部的一般工作流程，一个语言模型在接收 Token ID 序列后，通常会返回一个基于词汇表的概率分布，这个概率分布可以看成一个语言模型对下一个词的预测（不理解啥是概率分布，没关系，往下看吧，下面会解释）。

大语言模型一般分为训练和推理两个核心阶段。推理比较好理解，就是你每次向 ChatGPT 提问时，它会运用所学到的知识来回答你的问题、生成结果。而训练是指通过大量的资料输入，让模型学习，从而让它掌握内在规律、推理能力的过程。

好的，了解了两个核心阶段的概念后，再回到上面说的概率分布。

在训练模型时，我们可以使用这个概率分布来计算实际下一个词和预测下一个词之间的交叉熵损失，从而告诉模型输出结果好坏的标准。在模型推理时，利用概率分布可以预测下一个词是什么，从而生成文本结果。

可见，概率分布对于语言模型有着很重要的作用，下面就来讲一讲这个概率分布是什么以及它是怎么来的。

![大语言模型概览](/images/transformer-overview.png)

### 向量
在数学上，一个向量的维度就是它所包含的元素个数。一个向量的长度是 3:`[1, 2, 3]`，在编程里，通常说它的形状 `.shape` 是 3，表示为 `(3,)`。

### 张量
向量其实是张量的一种特殊情况，根据张量的形状，可以分为不同的情况：向量是一维张量、矩阵是二维张量、还有高阶张量是拥有更多维度的形状。

### 语义化
在拿到 Token ID 后，实际上得到的是一个矩阵，矩阵的形状是 `(batch_size, sequence_length)`（我们先不管这个 `batch_size` 和 `sequence_length` 是什么意思，把它看成一个二维数组，数组包含 `batch_size` 个元素，每个元素也是数组，每个元素长度是 `sequence_length`）。

在模型内部也有一个字典矩阵，形状是 `(vocabulary_size, embedding_dimension)`，它表示模型总共认识 `vocabulary_size` 个词（或 token），而且每个词都是一个长度为 `embedding_dimension` 的数组。

一个 4 行 12 列的 Token ID 矩阵可能长这样：
```
[[ 101,  800,  635, 1234,  102,    0,    0,    0,    0,    0,    0,    0],  # 第 1 句话
 [ 101, 1500,  999,  102,    0,    0,    0,    0,    0,    0,    0,    0],  # 第 2 句话
 [ 101,  750, 2890, 4633, 5821, 3333,  102,    0,    0,    0,    0,    0],  # 第 3 句话
 [ 101, 5432, 1022,  102,    0,    0,    0,    0,    0,    0,    0,    0]]  # 第 4 句话
```
对于 Token ID 的第一个元素 `token_ids[0, 0]` 值为 101，模型会从模型的字典矩阵中取出 `embedding_matrix[101]` 的数组，然后替换掉 `token_ids[0, 0]`。

对于 Token ID 的第二个元素 `token_ids[0, 1]` 值为 800，模型会从模型的字典矩阵中取出 `embedding_matrix[800]` 的数组，然后替换掉 `token_ids[0, 1]`。

以此类推，直到 Token ID 的所有元素都被模型的字典矩阵替换掉。这样得到的结果是什么？由于 Token ID 里每个数字都被一个数组替换掉了，所以结果张量的维度会加 1，也就是一个三维数组，数组包含 `batch_size` 个元素，每个元素也是二维数组，每个元素包含 `sequence_length` 个元素，每个元素的长度是 `embedding_dimension`，最终的形状为：`[batch_size, sequence_length, embedding_dimension]`，每个元素都是从模型的字典矩阵查出来的，这种格式正是模型期望的格式，它包含了丰富的语义信息，这个过程就是我们常说的语义化，英文里对应的术语是 `Token Embedding`。

### 信息加工
在经过 `Token Embedding` 之后，我们获得了一个语义化的张量，一个完整的 Transformer 模型还会继续处理这些信息，接下来是经过一个叫 Transformer Block 的黑盒子加工，在这个黑盒子里，张量会依次经过 RMSNorm 归一化、MultiHeadSelfAttention 多头自注意力处理、FFN 前馈网络，值得注意的是，我们的张量会多次经过 Transformer Block 加工，每次加工过后，都能加深语义理解，最后得到一个语义更丰富、对 Token 理解更深刻的张量。（Transformer Block 里面的模块我现在理解不是很到位，等以后有了更深刻理解，我会再写一篇文章）不过，这个张量的形状还是一样：`[batch_size, sequence_length, embedding_dimension]`。

从宏观角度来看，Transformer Block 会按照以下步骤进行加工：
```python
# x 就是语义化后得到的张量
x = rms_norm1(x)

x += attention(x, token_positions=positions)

x = rms_norm2(x)

return x + ffn(x)
```

经过语义化的张量包含了丰富的信息，接下来，这个张量会经过一次规范化强制将张量中的“尺度”调整到一个固定的范围。这个过程叫 RMSNorm，实际上 RMSNorm 是一个简化过的归一化过程，在保持性能的同时，通过简化操作来提高计算效率。这种简化在实践中被证明是有效的，特别是在大规模模型训练中。

### 查表
接下来张量会经过 Linear 层，从数学的角度来看，Linear 的过程就是矩阵乘法，一个具体的例子：
```python
# 输入向量
x = torch.tensor([0.1, 0.5, -0.2])

# 查询表
W = [
    [1.2, -0.5, 3.1],
    [0.8, 2.1, -1.0],
    [-0.2, 1.5, 0.6]
]
```
矩阵乘法 x * W 的计算过程：

计算第一个维度：
`0.1 * 1.2 + 0.5 * -0.5 + -0.2 * 3.1 = -0.75`

第二个维度：
`0.1 * 0.8 + 0.5 * 2.1 + -0.2 * -1.0 = 1.33`

第三个维度：
`0.1 * -0.2 + 0.5 * 1.5 + -0.2 * 0.6 = 0.61`

结果向量：`[-0.75, 1.33, 0.61]`，可以这样理解结果，它是 `x` 混合了 `W` 三种维度特性的新向量。

我们可以把 `W` 看成一个字典，我们希望 `x` 可以从这个字典里智能地提取信息，而不仅仅是机械地查找。

而在深度学习就是对更高维度张量进行计算，例如：x 的形状是 `[4, 12, 64]`，W 的形状是 `[64, 128]`，相当于把这个过程批量化、规模化了。PyTorch 框架中封装了高效的线性运算，框架内部通过 CUDA 优化计算，确保高吞吐量，适用于大规模神经网络。

### 预测结果
在 Transformer 的最终预测层，模型会为词汇表中的每个词生成一个原始分数（logits）。Softmax 函数的作用是接收这些分数，并通过指数运算和归一化，将它们转换为一个概率分布。这个分布代表了模型认为下一个词是某个词的置信概率。如例子所示：
```
softmax(z)_i = e^(z_i) / Σ(e^(z_j))
```

我们先把这个公式看成一个黑盒：
```
输入向量: [1.0, 2.0, 3.0]
最终结果: [0.0900, 0.2447, 0.6652]
```
可以看到输出结果最终加起来和是 1.0，从概率分布角度来看，这个结果代表了有 9% 的概率选择元素 1，24.5% 的概率选择元素 2，66.5% 的概率选择元素 3。也就是说，模型更倾向选择元素 3，但不是很绝对，可以相对确定地排除元素 1，数值最大的输入会获得最高的概率，但 softmax 也会为其他选项分配非零的概率，这反映了模型的不确定性，这就是 softmax 的原理。
